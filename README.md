# TP 3 — Statistiques d'une série de notes

Programme C++ qui lit les notes d'une UE et affiche minimum, maximum, moyenne, écart-type, admis et répartition par mention.

## Versions des outils

- g++ (Ubuntu 15.2.0-16ubuntu1) 15.2.0
- git version 2.53.0

## Compiler et exécuter

    g++ -std=c++23 -Wall -Wextra statistiques.cpp -o statistiques
    ./statistiques

Exemple : UE « POO », 4 étudiants, notes 8, 10, 12, 14 donnent une moyenne de 11,00 et un écart-type de 2,24.
